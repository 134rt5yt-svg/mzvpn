# mzvpn

Форк [FoxyVPN](https://github.com/Vauth/FoxyVPN) на Rust для десктопных платформ.

## Платформы

| ОС | Статус |
|---|---|
| Linux | Сделано |
| Windows | Запланировано |
| macOS | Рассматривается (может потребоваться отдельная адаптация) |

## Об оригинале

mzvpn FoxyVPN основан на Mozilla VPN — бесплатном VPN-сервисе с лимитом 50 ГБ трафика в месяц. Квота обновляется ежемесячно.
